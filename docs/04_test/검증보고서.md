## 3. 결함 목록 (심각도 순)

치명 0건 · 주요 4건 · 경미 12건 · 확인 필요 6건

### 3.1 주요

#### M-1. Ctrl+S가 작동하지 않는다 (FR-16)
- 위치: `src/wavetext/ui/main_window.py:171`, `:1140-1144`
- 원인 1: `self._act(m, "", self.save_text, "Ctrl+S").setVisible(False)`. Qt 6에서는 `setVisible(False)`를 호출하면 동작도 비활성화된다(`isEnabled()=False` 확인). 그래서 단축키가 전혀 반응하지 않는다.
- 원인 2: 화면에 보이게 고치더라도 `triggered(bool)` 신호가 `save_text(which=None)`에 `which=False`를 넘긴다(확인함). 그러면 `which is None` 분기를 건너뛰고 `else`로 가서 항상 ④만 저장한다. ②에 초점이 있어도 ②는 저장되지 않는다.
- 재현: 파일을 연다 → ②에 글자를 입력한다(수정됨 표시) → Ctrl+S를 누른다 → `full-stt\{원본}.stt.txt`가 만들어지지 않고 "수정됨"도 그대로다. ④에서도 똑같이 저장되지 않는다.
- 기대 동작: Ctrl+S를 누르면 초점이 있는 쪽 텍스트(②면 `{원본}.stt.txt`, ④면 `{원본}.stt-N.txt`)가 저장되고 "저장됨"으로 바뀐다. 숨긴 메뉴 항목 대신 화면에 보이는 동작이나 `QShortcut`을 쓰고, 람다로 감싸 `which` 인자가 넘어오지 않게 해야 한다.

#### M-2. 파일을 바꿨다 돌아온 뒤 늦게 도착한 분할 인식 결과가 사용자 텍스트를 덮어쓰거나 짝 없는 텍스트를 만든다 (FR-11, FR-12, FR-18)
- 위치: `src/wavetext/ui/main_window.py:967-978` (`_pair_stt_done`이 `pair.txt`에 조건 없이 씀), `:685-690` (다시 불러올 때 새 `Pair` 객체를 만들어 진행 중인 작업과 연결이 끊김), `:1093-1095` (삭제 표시가 새 객체에만 붙음)
- 재현 A (덮어쓰기): 구간을 만든다(인식 중) → PgDn → PgUp으로 돌아온다 → ④가 "인식 실패 · 직접 입력"으로 켜진다 → 문장을 고치고 [저장]을 누른다 → 인식 결과가 늦게 도착한다 → `stt-1.txt`가 인식 결과로 덮어써진다. 화면에는 사용자 문장이 계속 보이므로 사용자는 덮어쓰인 사실을 알 수 없다. 실시간 전송 속도(`realtime_pacing`) 때문에 30초 구간은 인식에만 30초 이상 걸린다. 따라서 이 시간 안에 파일을 오가는 일은 현실적으로 생긴다.
- 재현 B (짝 없는 파일): 위와 같이 돌아온 뒤 그 쌍을 Del로 삭제한다 → 늦게 결과가 도착한다 → `part-1.wav`는 없는데 `stt-1.txt`가 다시 생긴다. 다음에 이 파일을 열면 빈 음성 쌍으로 표시된다.
- 기대 동작: 진행 중인 작업을 파일 경로(번호) 기준으로 찾아 다시 불러온 쌍과 연결한다. 사용자가 저장했거나 삭제한 쌍에는 늦게 온 결과를 쓰지 않는다. 늦게 온 결과는 덮어쓰지 않고 버리거나 사용자에게 알린다.

#### M-3. 노이즈 제거와 학습용 Wav 저장이 화면 스레드에서 실행된다 (NFR-04)
- 위치: `src/wavetext/ui/main_window.py:933-946` (`estimate_profile`, `denoise.reduce`, `wavio.write`), `:973`, `:1151`, `:1161` (텍스트 저장)
- 재현: 30분 원본에서 처음 [학습용 파일 생성하기]를 누른다. 원본 전체로 잡음을 추정하는 데만 화면이 약 1.27초 멈춘다(10분 원본은 0.39초, 측정값). 여기에 구간 노이즈 제거와 파일 쓰기 시간이 더해진다. 네트워크 드라이브에 저장하면 더 오래 멈춘다.
- 기대 동작: 요구 문구대로 파일 저장(그리고 시간이 걸리는 노이즈 제거)을 작업 스레드에서 수행하고, 그동안 생성 버튼을 잠근다.

#### M-4. 최소 창 높이 860 때문에 1440×900 화면에서 창 아래가 작업 표시줄에 가려진다 (NFR-07)
- 위치: `src/wavetext/ui/main_window.py:84` `self.setMinimumSize(1440, 860)`

### 3.4 확인 결과 문제없음 (주요 점검 항목)

- 경계값: 0초 선택은 `waveform.py:99-100`에서 해제된다. 정확히 30초는 허용되고(`segment.py:19`, 시험 있음) 30.01초는 거부된다. 파일 끝을 넘는 구간은 끝까지만 잘린다(`segment.py:9-13`, 시험 있음). 0.05초 구간에도 페이드와 노이즈 제거가 정상 동작한다.
- 스테레오·24비트: 읽기·쓰기를 왕복해도 형식이 유지된다(`test_wav_round_trip`). 음성인식 요청 때만 8kHz·16비트·모노로 바꾼다(`convert.py:17-20`).
- 덮어쓰기 금지(Wav): 미리 존재 여부를 확인하고 임시 파일을 이름 바꾸기로 저장한다(Windows에서는 대상이 있으면 실패, `wavio.py:108-121`). 번호는 두 폴더의 최댓값 + 1이다(`paths.py:71-78`). 텍스트는 UTF-8(BOM 없음), 줄바꿈 LF로 저장한다.
- 스레드: `SttWorker`는 작업자 자신을 신호에 실어 메인 창의 바운드 메서드로 보낸다. 따라서 대기열 연결로 화면 스레드에서 처리된다(`workers.py:13-14`, `main_window.py:874-875`). 원본 인식은 중지하거나 파일을 바꾼 뒤 도착한 결과를 버린다(`main_window.py:891`). 같은 화면에서 쌍을 삭제한 뒤 늦게 온 결과도 저장하지 않는다(`:970`).
- 저장하지 않은 텍스트 확인: 파일 이동, 폴더 변경, 쌍 전환, 새 쌍 생성, 창 닫기에서 모두 확인 창이 뜨고, 취소하면 그대로 남는다(`main_window.py:551, 656, 929, 1026, 1229`).
- API 키: 화면(설정 창)에는 마스킹해서 표시한다. 연결·전송 오류 문구에서는 키를 제거한다. WaveText 설정 파일에는 키를 저장하지 않는다. 배포판에서는 키 파일을 지운다.
- 단축키와 텍스트 입력: 입력칸에 초점이 있으면 Space, Shift+Space, `[`, `]`, Del, ←→, Ctrl+A, Shift+S/A는 글자 편집에 쓰인다(Qt ShortcutOverride, `test_shortcuts.py`와 임시 시험으로 확인). Esc(선택 해제)와 PgUp/PgDn(파일 이동, 미저장이면 확인 창)은 입력 중에도 단축키로 동작한다. 동작 자체는 피해가 작아 결함으로 분류하지 않았다.
