## 3. 실제 녹취 노이즈 제거 확인

샘플 1.0~7.0초 구간, 0.5초 단위 RMS 비율(처리 후 / 처리 전):

| 강도 | 음성 구간 | 무음 구간 |
|---|---|---|
| 약 | 1.00 | 0.60~0.90 |
| 중 | 1.00 | 0.28~0.83 |
| 강 | 1.00 | 0.08~0.72 |

음성은 유지되고 무음 구간 잡음만 줄어든다. 청취 확인은 현장 녹취로 추가 필요(open_issues OI-02).
