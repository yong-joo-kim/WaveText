# 미결·가정 사항

| 번호 | 내용 | 현재 가정 | 확인 필요 |
|---|---|---|---|
| OI-01 | ④ [② 문장 가져오기] 범위 | 시안은 선택 구간의 단어만 가져왔으나, 실제 인식 결과에는 단어별 시간 정보가 없다(`word_alignment: false`). ② 전체를 가져와 사용자가 편집하는 것으로 구현 | 단어 시간 정보 사용 여부 |
| OI-02 | 노이즈 제거 알고리즘 | 원본 파일 전체에서 에너지가 낮은 구간으로 잡음 특성을 추정하는 스펙트럴 게이팅 | 현장 녹취로 강도별 청취 확인 |
| OI-03 | Pretendard GOV 서체 | 서체 파일이 있으면 `assets/fonts/`에서 불러오고, 없으면 맑은 고딕 사용 | 서체 파일 제공 여부 |
