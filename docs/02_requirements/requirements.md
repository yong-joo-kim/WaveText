# WaveText 요구사항 정의서

- 작성일: 2026-10-23 · 근거: 개발계획서, 화면설계서(승인), 사용자 확정 사항
- 상태: 승인 (사용자 "시안 승인한다. 구현 진행해", 2026-10-23)

## 1. 기능 요구 (FR)

| 번호 | 요구 | 수용 기준 |
|---|---|---|
| FR-01 | 원본 음성 폴더 지정(필수) | [저장 폴더] 창에서 원본 음성 폴더를 비우고 확인하면 적용되지 않고 오류 안내가 표시된다. 지정하면 폴더의 `.wav` 목록을 읽고 첫 미처리 파일을 연다. |
| FR-02 | 저장 폴더 5곳 지정 | 원본 음성인식 Text / 사용자 분할 음성 Wav / 사용자 분할 음성인식 Text / 자동 분할 음성 Wav / 자동 분할 음성인식 Text 폴더를 각각 지정한다. 비워 두면 각각 `원본\full-stt\`, `원본\manual-part-wav\`, `원본\manual-part-stt\`, `원본\auto-part-wav\`, `원본\auto-part-stt\`를 쓰고, 저장 시 폴더가 없으면 만든다. 원본 음성인식 Text 폴더는 사용자 분할과 자동분할생성이 함께 쓴다. |
| FR-03 | 파일 목록 | 서랍 방식 목록에 파일 이름, 길이, 처리 상태(✔ n쌍 / ○ 미처리)를 표시한다. 검색과 상태 필터(전체·미처리·생성 완료)를 제공한다. 분할 파일(`*.part-N.wav`)은 원본 목록에서 제외한다. 쌍 개수에는 사용자 분할 음성 Wav 폴더와 자동 분할 음성 Wav 폴더의 파일을 모두 센다. |
| FR-04 | 이전/다음 파일 | PgUp/PgDn 또는 버튼으로 이동한다. 저장하지 않은 텍스트가 있으면 저장 여부를 묻는다. |
| FR-05 | 원본 파형 표시 | 진폭 눈금, 시간 눈금자, 전체 보기 띠를 표시한다. 휠·버튼으로 확대/축소하고, 전체 보기 띠 클릭으로 보기 위치를 옮긴다. |
| FR-06 | 원본 재생 | [▶ 원본 재생]/[❚❚ 일시정지], [구간 재생], [■ 정지]. 재생 위치를 파형과 시간 표시창에 표시한다. Space / Shift+Space. |
| FR-07 | 구간 마크 | 파형을 끌어 선택, "시작"/"끝" 경계를 끌어 조정, `[` `]`로 재생 위치를 마크, 숫자 입력(0.001초). Esc로 해제. |
| FR-08 | 발췌 길이 제한 | 선택 구간이 30초를 넘으면 [학습용 파일 생성하기]가 비활성화되고 길이를 빨간색으로 표시한다. 0.05초 미만도 비활성화. |
| FR-09 | 원본 음성인식 | [음성인식 실행](F5)으로 원본 전체를 음성인식 서버에 보내 결과를 ②에 표시하고 `{원본이름}.stt.txt`로 **자동 저장**한다(기존 파일 덮어쓰기). 이때 **단어별 시간 정보**(`word_alignment`)를 함께 받아 `{원본이름}.stt.json`에 저장한다. 진행률 표시, 실행 중 [인식 중지] 가능. 선택 구간만 인식(Shift+F5)한 결과는 자동 저장하지 않는다. |
| FR-10 | 학습용 파일 생성 | 선택 구간을 잘라 노이즈 제거와 양 끝 10ms 페이드를 적용해, 원본과 같은 형식(샘플레이트·비트·채널)으로 `{원본이름}.part-N.wav`를 분할 Wav 폴더에 저장한다. |
| FR-11 | 선택 구간 문장 자동 출력·저장 | 학습용 파일을 생성하면 분할 음성을 **다시 인식하지 않고**, ② 원본 인식의 단어 시간으로 **선택 구간에 해당하는 문장만** 가져와 ④에 표시하고 `{원본이름}.stt-N.txt`(UTF-8)로 자동 저장한다(단어 가운데 시각이 구간 안에 있으면 포함). 원본 인식 결과가 없으면 빈 파일을 만들고 "문장 없음 · 가져오기 필요"를 표시한다. |
| FR-12 | 번호 규칙 | N은 1부터 시작하며, 분할 Wav 폴더와 분할 Text 폴더에 있는 같은 원본의 기존 번호 중 가장 큰 값 + 1로 정한다. 기존 파일을 덮어쓰지 않는다. |
| FR-13 | 생성 결과 표시 | ③에 생성된 쌍 목록(part-N, 원본 구간)과 파형을 표시한다. 쌍 클릭: 보기, 더블클릭: ①에 구간 다시 표시. |
| FR-14 | 노이즈 제거 비교 재생 | ③에서 [노이즈 제거 후]/[원음]을 고르면 파형과 재생이 바뀐다. 원음은 파일로 저장하지 않는다. Ctrl+Space. |
| FR-15 | 노이즈 제거 강도 | 사용 안 함 / 약 / 중(기본) / 강. 생성 시 선택한 강도를 적용한다. |
| FR-16 | 텍스트 편집·저장 | ②와 ④를 편집할 수 있다. 편집하거나 ④에 문장을 가져오면 "수정됨" 표시와 함께 [저장] 버튼이 **활성화**되고, 누르면(또는 Ctrl+S) 저장 후 다시 비활성화된다. 기존 파일이 있으면 덮어쓴다. ②는 `{원본이름}.stt.txt`(원본 음성인식 Text 폴더), ④는 `{원본이름}.stt-N.txt`. |
| FR-17 | ④ 보조 버튼 | 필요할 때 쓰는 버튼 3개를 구분해 둔다. [문장 전체 가져오기]: ② 문장 전체. [선택 구간 문장 가져오기]: ③에서 선택한 학습용 Wave의 원본 구간 문장만. (두 버튼은 가져온 뒤 [저장] 활성화) [음성인식 실행](Ctrl+F5): 선택한 분할 음성파일을 다시 인식해 `stt-N.txt`에 덮어써 자동 저장, 실패하면 기존 유지. |
| FR-18 | 학습용 쌍 삭제 | ③에서 선택한 쌍을 [▶ 재생] 옆 [🗑 삭제] 단추, 메뉴 또는 Del로 삭제한다. 쌍이 없거나 생성 중이면 단추를 끈다. 확인 창을 거쳐 `part-N.wav`와 `stt-N.txt`를 함께 삭제한다. |
| FR-19 | 상태줄 | 1행: 채널, 길이, 선택 구간 `a to b (len)`, 메시지. 2행: `원본`, 길이, `18.212초 · Wave PCM signed 16 bit, 8000 Hz, 128 kbps, mono` 형식, 진행 현황과 저장 폴더(줄임 표시: 원본 음성인식 Text / 사용자 분할 음성 Wav / 사용자 분할 음성인식 Text / 자동 분할 음성 Wav / 자동 분할 음성인식 Text). |
| FR-20 | 음성인식 서버 설정 | [설정] → [음성인식 서버 설정]에서 서버 주소, 포트, 접속 방식(ws/wss), API 키(비밀번호 입력, "변경할 때만 입력", `(sk-******** 저장됨)` 표시), 모델을 입력하고 [연결 확인](`/health`)으로 점검한다. 값은 WaveText `config.local.json`에만 저장하며 다른 프로그램의 설정은 읽지 않는다. 기본값: ws / 8081 / model_v2, 서버 주소와 API 키는 기본값 없음. |
| FR-21 | 단축키 안내 | F1로 단축키 표를 표시한다. |
| FR-28 | 리얼타임 페이싱 | 도구 모음에서 노이즈 제거 옆의 [리얼타임 페이싱](사용·사용 안 함, 기본 사용 안 함)으로 음성을 재생 속도에 맞춰 서버로 보낼지 정한다. 값은 `config.local.json`에 저장한다. |
| FR-22 | 자동분할생성 창 | 상단 메뉴 [자동분할생성](F6)을 누르면 별도 창이 열린다. 창이 열려 있는 동안 메인 창은 쓸 수 없고, 메인 창의 ③④ 학습용 생성 화면은 바뀌지 않는다. 창 안에 파일 선택(이전·다음·목록), 파형 확대·축소·구간 맞춤·전체(Shift+↑·↓·S·A, 세로 확대 Ctrl+↑·↓), 노이즈 제거, 리얼타임 페이싱, 원본 파형, 원본 인식 문장(읽기 전용), 구간 목록을 둔다. 원본 문장 수정은 메인 창 ②에서 한다. |
| FR-23 | 구간 자동 분할 | 이 화면에서 원본 전체 음성인식이 끝나면(이전 구간이나 학습용 저장본이 없을 때) 또는 [자동 분할 실행]을 누르면 단어 시간과 원본 에너지로 묵음 구간과 문장 단위를 고려해 최소 4초, 최대 15초 구간으로 나눈다. 단어를 자르지 않고, 단어가 없는 묵음은 구간에 넣지 않으며, 구간은 겹치지 않는다. 합쳐도 4초를 못 채우는 구간은 "짧음"으로 표시하고 저장 선택을 끈다. 도구막대의 노이즈 제거 강도와 10ms 페이드를 적용한다. |
| FR-24 | 파형·구간 위치 동기화 | ①에 구간을 띠로 표시한다(번호·기호 포함). 파형을 클릭하면 그 시각의 구간 행을 선택해 보여 주고 ②에서 구간 문장과 단어를 강조한다. 구간 사이를 누르면 가까운 구간을 고른다. 행을 고르면 파형이 그 구간으로 이동한다. |
| FR-25 | 구간 재생·문장 수정 | 행마다 ▶(저장될 소리 재생, Ctrl+Space)와 문장 수정칸이 있다. 재생 위치는 ①에 원본 시간으로 표시한다. 수정한 문장과 저장 선택은 구간 기록(`{원본이름}.split.json`, 원본 음성인식 Text 폴더)에 자동 저장되어 다시 열어도 유지된다. 원본 길이가 달라졌으면 기록을 쓰지 않는다. |
| FR-26 | 학습용 저장 | [선택 저장](Ctrl+S)으로 선택한 쌍을 자동 분할 음성 Wav 폴더(기본 `원본\auto-part-wav`, `{원본이름}.part-N.wav`)와 자동 분할 음성인식 Text 폴더(기본 `원본\auto-part-stt`, `{원본이름}.stt-N.txt`)에 저장한다. 원본 음성인식 결과(`{원본이름}.stt.txt`·`.stt.json`·`.split.json`)는 따로 복사하지 않고 원본 음성인식 Text 폴더(`full-stt`)의 것을 함께 쓴다. 원본 Wave는 복사하지 않는다. 사용자 분할 폴더(`manual-part-wav`·`manual-part-stt`)에는 쓰지 않는다. N은 분리 시점에 정해 바꾸지 않으므로 번호에 빈틈이 생길 수 있다. ②가 수정 중이거나 선택한 구간의 문장이 비어 있으면 저장하지 않는다. 저장 후 해제한 쌍은 확인을 거쳐 삭제한다. |
| FR-27 | 다시 자동 분할 | 이전 구간이나 저장본이 있으면 음성인식이 끝나도 저절로 나누지 않고, 구간이 이전 결과 기준임을 표시한다. [자동 분할 실행]은 확인(기본 단추 '아니요')을 거치며, 음성인식 중에는 분리와 저장을 시작하지 않는다. 확인하면 분리가 성공한 뒤 이전 학습용 저장본을 삭제하고, 거절하면 이전 구간을 유지한다. |
| FR-29 | 구간 시작·끝 수정 | 구간을 고르면 ① 파형의 그 띠에 "시작"/"끝" 경계가 표시되고, 끌어서 시작·끝을 고친다. 이웃 구간과 겹치지 않고, 0.5초보다 짧거나 30초보다 길어지지 않는다. 고치면 구간·길이·상태(짧음·김)와 저장될 소리를 새 구간으로 바꾸고, 문장을 직접 고치지 않았으면 문장도 새 구간의 단어로 바꾼다. 이미 저장한 쌍은 "수정됨"으로 표시하고 [선택 저장] 때 Wav와 Text를 새 구간으로 다시 저장한다. 고친 구간은 구간 기록에 남아 다시 열어도 유지된다. 소리 준비·저장 중에는 고칠 수 없다. |
| FR-30 | 구간 합치기 | 구간을 고르고 [앞 구간과 합치기](Ctrl+Shift+↑) 또는 [뒤 구간과 합치기](Ctrl+Shift+↓)를 누르면 바로 이웃한 구간과 하나로 합친다. 합친 구간은 앞 구간의 번호를 쓰고, 앞 구간 시작부터 뒤 구간 끝까지(사이 묵음 포함)로 정한다. 두 문장 모두 직접 고치지 않았으면 새 구간의 단어로 문장을 만들고, 아니면 두 문장을 이어 붙인다. 상태(짧음·김)와 저장될 소리를 새로 만들고, 저장 선택은 둘 중 하나라도 켜져 있으면 켠다(짧음이면 끔). 합친 길이가 30초를 넘으면 합치지 않는다. 없어진 구간의 저장본은 [선택 저장] 때 확인(기본 '아니요')을 거쳐 삭제하고, 합친 구간의 Wav·Text를 다시 저장한다. 첫 구간의 앞·마지막 구간의 뒤로는 합칠 수 없고, 소리 준비·저장 중에는 합칠 수 없다. |

## 2. 비기능 요구 (NFR)

| 번호 | 요구 | 수용 기준 |
|---|---|---|
| NFR-01 | API 키 보호 | API 키를 화면·로그·오류 메시지에 그대로 표시하지 않는다(앞 3자 + `********`, 8자 이하는 모두 가림). 키는 실행 폴더의 `config.local.json`에만 저장하며, 이 파일은 저장소(.gitignore)와 배포판에서 제외한다. |
| NFR-02 | 폐쇄망 휴대용 배포 | 설치·관리자 권한 없이 zip을 풀어 실행한다. 인터넷 연결이 필요 없다. |
| NFR-03 | 대량 파일 | 3,000개 이상 파일 폴더를 열 때 헤더만 읽어 목록을 만들고, 파형은 선택한 파일만 읽는다. |
| NFR-04 | 화면 응답성 | 음성인식·파일 저장은 작업 스레드에서 수행해 화면이 멈추지 않는다. |
| NFR-05 | 입력 형식 | PCM WAV(8/16/24/32비트 정수, 모노·스테레오)를 지원한다. 그 외 형식은 이유를 표시하고 건너뛴다. 음성인식 요청 시에만 8kHz·16비트·모노로 변환한다. |
| NFR-06 | 디자인 | 화면설계서 7장(KRDS 표준형: 색 토큰, Pretendard GOV 계열 서체, 반경, 간격)을 따른다. 상태는 기호·글자를 함께 표시한다. |
| NFR-07 | 최소 화면 | 1440×900 이상에서 가로 넘침 없이 표시한다. |
| NFR-08 | 문자 인코딩 | 텍스트 파일은 UTF-8(BOM 없음)로 저장하고, 한글 경로를 지원한다. |

## 3. 제약 (P4 1차 검증 반영)
- FR-13·FR-14: 분할 구간(시작~끝)은 `{원본이름}.stt.json`(원본 음성인식 Text 폴더)에 기록하므로 다시 연 파일에서도 구간 표시·원음 비교·선택 구간 문장 가져오기를 제공한다. 이 기록이 없는 예전 쌍(v0.1.2 이전 생성)은 길이만 표시한다.
- NFR-05: 3채널 이상 WAV는 지원하지 않는다(읽을 때 이유를 표시하고 목록에서 ✕로 건너뜀).
