## 3. 작업 흐름

1. [저장 폴더] 창에서 원본 음성 폴더(필수)를 지정하고, 필요하면 저장 폴더 3곳을 지정한다. 원본 음성 폴더를 지정하면 첫 미처리 파일을 연다.
2. ①의 파형을 보고 들으면서(Space, Shift+Space) 명료한 구간을 끌어 선택한다. 필요하면 `[` `]`로 재생 위치에 마크한다.
3. (선택) [음성인식 실행]으로 ②에서 전체 문장을 확인한다.
4. **[학습용 파일 생성하기]** (Ctrl+Enter)를 누른다.
   - 구간을 잘라내고, 노이즈를 제거하고, 양 끝에 10ms 페이드를 적용해 원본과 같은 형식으로 저장한다 → `원본이름_0001.wav`
   - 잘라낸 음성을 자동 인식한 결과를 저장한다 → `원본이름_0001.txt`
   - 결과는 ③과 ④에 바로 표시한다.
5. ③을 재생(Ctrl+Space)해 들어보고, ④의 텍스트를 고친 뒤 저장(Ctrl+S)한다.
6. 같은 파일에서 다른 구간을 반복하거나, PgDn으로 다음 파일로 넘어간다.

## 5. 파일 규칙 (2026-10-23 사용자 확정)

[저장 폴더 설정] 창의 항목 이름과 규칙입니다.

| 창의 항목 | 저장 파일 | 미지정 시 |
|---|---|---|
| **원본 음성 폴더** (필수) | 작업할 원본 `.wav` 파일이 있는 폴더 | 비울 수 없음. 비우고 [확인]을 누르면 빨간 테두리와 "원본 음성 폴더를 입력하세요. (필수)"를 표시하고 적용하지 않음 |
| **원본 음성인식 Text 폴더** | ② 원본 전체 인식 결과 `{원본이름}.stt.txt` | `원본\full-stt\` |
| **분할 Wav 폴더** | ③ 분할 음성 `{원본이름}.part-1.wav`, `.part-2.wav` … | `원본\part-wav\` |
| **분할 음성인식 Text 폴더** | ④ 분할 음성 인식 결과 `{원본이름}.stt-1.txt`, `.stt-2.txt` … (같은 번호끼리 한 쌍) | `원본\part-stt\` |

- `원본`은 원본 음성 폴더를 뜻한다. 세 저장 폴더는 서로 영향을 주지 않으며, 비워 둔 항목만 각자의 기본 폴더에 저장한다.
- 빈 입력칸에는 실제로 저장될 기본 위치를 흐리게 보여준다. 원본 음성 폴더를 바꾸면 이 안내도 함께 바뀐다.
- **발췌 길이**: 한 구간은 최대 30초다. 30초를 넘으면 [학습용 파일 생성하기]를 막고 길이를 빨간색으로 표시한다.
- **번호**: 한 원본에서 여러 쌍을 만들 수 있다. 번호는 저장 폴더의 기존 `part-N` / `stt-N`을 확인해 다음 번호로 이어서 매긴다(덮어쓰기 없음).
- **형식**: 발췌 Wav는 원본과 같은 형식(예: PCM 16bit, 8000Hz, mono)으로 저장한다. Text는 UTF-8, 한 줄 전사다.

## 7. 디자인 스타일 (KRDS 표준형 적용)

기준 문서: `docs/reference/ui-guideline/디지털 정부서비스 UIUX 가이드라인(2025.08).pdf`. 괄호 안은 해당 쪽입니다.

### 7.1 색상 (p75~101)
팔레트 값은 PDF 견본에서 추출했고, 시안 `mockup.html`의 `:root`에 프리미티브 토큰과 시멘틱 토큰으로 정의했습니다.

| 용도 | 토큰 | 값 |
|---|---|---|
| 주요 버튼, 선택 상태, 파형 | primary-50 / hover 60 / 누름 70 | `#256ef4` / `#0b50d0` / `#083891` |
| 선택된 항목 배경 | primary-5, primary-10 | `#ecf2fe`, `#d8e5fd` |
| 화면 바탕 (elevation -1) | gray-5 | `#f4f5f6` |
| 패널 (elevation 0) | gray-0 | `#ffffff` |
| 패널 하단 띠, 시간 표시창 | secondary-5 / 글자 secondary-70 | `#eef2f7` / `#063a74` |
| 본문 / 보조 글자 | gray-90 / gray-60 | `#1e2124` / `#58616a` (4.5:1 이상) |
| 구분선 / 입력칸 테두리 | gray-20 / gray-50 | `#cdd1d5` / `#6d7882` (입력 테두리 매직넘버 50) |
| 마크 경계(시작/끝) | warning-30 | `#ffb114` + "시작"·"끝" 글자 탭 |
| 재생 위치 | gray-90 | `#1e2124` (적색 대신 진한 선, 적·황 혼동 방지) |
| 상태 배지 | success / warning / danger 5·10·60 | ✓ 완료, ● 진행 중, ✎ 수정됨 기호를 함께 표시 |
| 시안 안내 | information 5·10·60 | `#e7f4fe` / `#d3ebfd` / `#096ab3` |

- 60-30-10 원칙: 흰색·회색 바탕 60%, 보조(secondary·회색 글자) 30%, 주요 색(primary) 10%로 맞춥니다.
- 색각이상자 고려(p78~79): 상태는 색만으로 구분하지 않고 기호·글자를 함께 표시합니다. 적색·녹색을 나란히 쓰지 않습니다.
- 비활성 버튼은 투명도를 쓰지 않고 gray-10 바탕, gray-50 글자로 표시합니다(p101).

### 7.2 타이포그래피 (p103~125)
- 서체: Pretendard GOV. 구현 시 폐쇄망을 고려해 폰트 파일을 프로그램에 내장합니다. 시안은 설치된 서체가 없으면 맑은 고딕으로 표시됩니다.
- 굵기: regular 400과 bold 700만 사용합니다. 줄 간격은 150%입니다.
- 크기: 인식 텍스트(②④)는 17px(body medium), 패널 제목은 17px bold, 일반 UI와 버튼은 15px(label small)입니다. 보조 정보(상태줄, 경로, 도구 이름)는 13px(xsmall)이며 꼭 필요한 곳에만 씁니다.
- 숫자(시간, 길이, 눈금)는 고정폭 서체(D2Coding, 없으면 Consolas)를 씁니다.

### 7.3 형태 (p129~131)
| 크기 단계 | 반경 | 적용 |
|---|---|---|
| xsmall | 2px | 배지 |
| small | 4px | 칩(파일 쌍 목록), 단축키 표시 |
| medium | 6px | 버튼, 입력칸, 선택 상자, 시간 표시창 |
| large | 10px | 4분할 패널, 파일 목록 서랍, 단축키 안내 |
| xlarge | 12px | 저장 폴더 모달 |

### 7.4 간격·높이·엘리베이션 (p152~160, p183~191)
- 간격은 8포인트 단위(4·8·16·24px)로 맞춥니다. 패널 사이는 8px, 입력칸 안쪽 여백은 16px, 모달 안쪽 여백은 24px입니다.
- 버튼 높이: 주 버튼 40px(small), 패널 안 버튼 32px(xsmall), 도구 모음 아이콘 버튼 48px입니다.
- 그림자: 패널은 1단계, 메뉴는 2단계, 서랍과 안내창은 3단계, 모달은 4단계입니다.
- 키보드 초점은 primary-50 색 2px 외곽선으로 항상 보이게 합니다.
