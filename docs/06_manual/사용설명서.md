# WaveText 사용설명서

WaveText는 녹취 음성 파일에서 음성이 명료한 구간을 골라, 음성인식 학습용 **분할 음성파일(Wav)** 과 **음성인식 Text** 쌍을 만드는 프로그램입니다.

## 1. 설치와 실행
1. `WaveText_portable_v버전.zip`을 원하는 폴더에 풉니다. 설치나 관리자 권한, 인터넷 연결이 필요 없습니다.
2. `WaveText.exe`를 실행합니다.
3. 처음 실행하면 [저장 폴더 설정] 창이 열립니다. **원본 음성 폴더**를 지정하고 [확인]을 누릅니다.

### 음성인식 서버 연결
처음 한 번 [설정] → [음성인식 서버 설정]에서 서버 주소와 API 키를 입력합니다.

| 항목 | 내용 |
|---|---|
| 서버 주소 / 포트 | 음성인식 서버 주소(관리자에게 확인)와 포트(기본값 8081) |
| 접속 방식 | ws 또는 wss (기본값 ws) |
| API 키 | 처음에는 꼭 입력합니다. 이후에는 바꿀 때만 입력하며, 저장된 키는 `(sk-******** 저장됨)`처럼 앞 3자만 보입니다 |
| 모델 | model_v2 / model_v1 / model_v3 (기본값 model_v2) |

- [연결 확인]으로 서버 연결을 점검하고 [저장]을 누릅니다. 값은 WaveText.exe 옆 `config.local.json`에 저장됩니다.
- ② 영역 하단에 서버 주소와 모델이 표시됩니다. "✕ 음성인식 API 키 미설정" 또는 "✕ 음성인식 서버 미설정"이 보이면 위 설정을 입력하세요.

## 2. 화면 구성

| 영역 | 내용 |
|---|---|
| ① 원본 파형 (왼쪽 위) | 원본 음성 파형. 재생, 구간 선택, 확대·축소 |
| ② 원본 음성인식 결과 (오른쪽 위) | 원본 전체를 인식한 문장. 수정·저장 가능 |
| ③ 생성된 학습용 Wave (왼쪽 아래) | 만든 분할 음성파일 목록(part-1, part-2 …)과 파형 |
| ④ 학습용 Text (오른쪽 아래) | 분할 음성파일의 인식 문장. 들어보고 고친 뒤 저장 |
| 상태줄 (맨 아래) | 1행: 채널·길이·선택 구간·메시지 / 2행: 원본 형식(예: `18.212초 · Wave PCM signed 16 bit, 8000 Hz, 128 kbps, mono`)·진행 현황·저장 폴더 |

## 3. 저장 폴더와 파일 이름

[저장 폴더] 버튼(Ctrl+O)으로 설정합니다.

| 항목 | 저장 파일 | 비워 두면 |
|---|---|---|
| 원본 음성 폴더 (필수) | 작업할 원본 `.wav` | 비울 수 없음 |
| 원본 음성인식 Text 폴더 | `원본이름.stt.txt` | `원본 폴더\full-stt\` |
| 분할 Wav 폴더 | `원본이름.part-1.wav`, `.part-2.wav` … | `원본 폴더\part-wav\` |
| 분할 음성인식 Text 폴더 | `원본이름.stt-1.txt`, `.stt-2.txt` … | `원본 폴더\part-stt\` |

- 같은 번호의 `part-N.wav`와 `stt-N.txt`가 한 쌍입니다.
- 번호는 기존 파일 다음 번호로 이어지며, 기존 파일을 덮어쓰지 않습니다.
- 텍스트는 UTF-8로 저장합니다.

## 4. 작업 순서
1. **원본 파일 열기**: 원본 음성 폴더를 지정하면 아직 작업하지 않은 첫 파일이 열립니다. [◀ 이전]/[다음 ▶](PgUp/PgDn) 또는 [파일 목록](Ctrl+L)으로 이동합니다. 목록의 ✔는 학습용 파일을 만든 원본, ○는 아직 작업하지 않은 원본입니다.
2. **원본 음성인식**: ② [음성인식 실행](F5)을 누릅니다. 원본 전체 문장이 ②에 표시되고 `원본이름.stt.txt`로 **자동 저장**됩니다(기존 파일 덮어쓰기). 단어별 시각은 `원본이름.stt.json`에 함께 저장됩니다. 문장을 고치면 [저장] 버튼이 켜지고, 누르면 저장됩니다.
3. **들어보고 구간 선택**: [▶ 원본 재생](Space)으로 들으면서 ① 파형을 마우스로 끌어 선택합니다.
   - 노란 "시작"/"끝" 경계선을 끌어 미세 조정합니다.
   - 재생하면서 `[`, `]`를 누르면 그 위치가 시작/끝이 됩니다. 하단 숫자 칸에 초 단위로 직접 입력할 수도 있습니다.
   - [구간 재생](Shift+Space)으로 선택한 부분만 들어봅니다.
   - 구간은 **최대 30초**입니다. 넘으면 길이가 빨간색으로 표시되고 생성 버튼이 꺼집니다.
4. **학습용 파일 생성하기**(Ctrl+Enter):
   - 선택 구간을 잘라 노이즈를 제거하고 ③에 `part-N.wav`로 저장합니다.
   - ④에는 ② 원본 인식 결과 중 **선택한 구간의 문장만** 자동으로 들어가 `stt-N.txt`로 저장됩니다(분할 음성을 다시 인식하지 않음).
5. **확인·수정**: ③ [▶ 재생](Ctrl+Space)으로 들어보고, ④의 틀린 글자를 고치면 [저장] 버튼이 켜집니다. 누르면(Ctrl+S) `stt-N.txt`에 덮어써 저장합니다.
6. 같은 파일에서 다른 구간을 반복하거나 다음 파일로 넘어갑니다.

### ④ 학습용 Text 버튼 (필요할 때)
- [문장 전체 가져오기]: ② 문장 전체를 가져옵니다. 필요한 부분만 남기고 [저장]합니다.
- [선택 구간 문장 가져오기]: ③에서 고른 학습용 Wave 구간의 문장만 가져옵니다. 가져온 뒤 [저장]합니다.
- [음성인식 실행](Ctrl+F5): 분할 음성파일을 다시 인식해 `stt-N.txt`에 덮어써 자동 저장합니다. 실패하면 기존 문장을 그대로 둡니다.
- [선택 구간 문장 가져오기]는 서버가 준 단어별 시각으로 자릅니다. ②에서 직접 고친 글자는 반영되지 않습니다.

### 노이즈 제거
- 도구 모음의 [노이즈 제거]에서 강도(사용 안 함·약·중·강)를 고릅니다. 기본은 "중"입니다.
- ③의 [노이즈 제거 후]/[원음]을 바꾸면 파형과 재생 소리가 바뀌어 효과를 비교할 수 있습니다. 저장되는 파일은 항상 "노이즈 제거 후"입니다.
- 음성이 뭉개지면 강도를 낮춰 다시 생성하세요. 잘못 만든 쌍은 ③에서 선택하고 Del로 삭제합니다.

### 문장이 비어 있으면
원본 음성인식을 하지 않고 생성하면 ④가 비어 있고 "✕ 문장 없음 · 가져오기 필요"가 표시됩니다. ② [음성인식 실행] 후 ④ [선택 구간 문장 가져오기]를 누르거나, ④ [음성인식 실행]으로 분할 음성을 인식하세요.

## 5. 단축키

| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| Space | 원본 재생 / 일시정지 | Ctrl+Enter | 학습용 파일 생성 |
| Shift+Space | 선택 구간 재생 | F5 / Shift+F5 | 원본 인식 / 선택 구간만 인식 |
| Ctrl+Space | 학습용 파일 재생 | Ctrl+S | 텍스트 저장 |
| Ctrl+F5 | 학습용 파일 다시 인식 | | |
| `[` / `]` | 시작 / 끝 마크 | PgUp / PgDn | 이전 / 다음 파일 |
| ← → (Shift) | 재생 위치 0.1초(1초) 이동 | Shift+↑ / ↓ | 확대 / 축소 |
| Esc | 마크 해제 | Shift+S / Shift+A | 구간 맞춤 / 전체 보기 |
| Del | 학습용 파일 쌍 삭제 | Ctrl+L | 파일 목록 |
| Ctrl+O | 저장 폴더 설정 | F1 | 단축키 안내 |

글자 입력칸(②④)에 커서가 있을 때는 Space·[·]·Del 등이 글자 입력으로 동작합니다. 단축키를 쓰려면 파형을 한 번 클릭하세요.

## 6. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "✕ 음성인식 서버 미설정" / "✕ 음성인식 API 키 미설정" | [설정] → [음성인식 서버 설정]에서 서버 주소·포트·API 키 입력 |
| 인식 실패 (연결 실패) | 서버 전원·네트워크, 설정 창의 [연결 확인] |
| ④ "✕ 문장 없음 · 가져오기 필요" | ② 원본 음성인식 후 ④ [선택 구간 문장 가져오기] |
| 소리가 안 남 | 스피커/이어폰 연결, 윈도우 기본 출력 장치 |
| "읽을 수 없는 파일" | PCM WAV만 지원합니다(8/16/24/32비트 정수). MP3나 32비트 실수 WAV는 변환 후 사용 |
| 목록에 파일이 없음 | 원본 음성 폴더 경로. `*.part-N.wav`는 분할 파일이라 목록에서 뺍니다 |
